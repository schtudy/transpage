# 담다 – 배포 메모 (폴더 최소화 버전)

GitHub 저장소 최상단에 이 파일들이 그대로 보여야 합니다:
index.html guide.html about.html privacy.html terms.html 404.html
style.css app.js favicon.svg robots.txt sitemap.xml ads.txt _headers

폴더가 필요한 파일은 하나뿐입니다:
functions/api/fetch.js
→ GitHub "Add file > Create new file" 이름 칸에 `functions/api/fetch.js`를 그대로 입력 후 내용 붙여넣기
