휴대폰에서 웹페이지를 HTML 파일로 저장하는 3가지 방법

작성 2026.09.18 · 담다

컴퓨터에서는 Ctrl+S 한 번이면 웹페이지를 파일로 저장할 수 있습니다. 그런데 휴대폰에서는 같은 일을 하려고 메뉴를 한참 뒤져도 원하는 형식이 나오지 않는 경우가 많습니다. 이 글에서는 안드로이드와 아이폰에서 쓸 수 있는 방법을 장단점과 함께 정리했습니다.

방법 1. 브라우저 기본 기능 쓰기

안드로이드 크롬

크롬 오른쪽 위 점 세 개 메뉴에서 다운로드(아래 화살표) 아이콘을 누르면 현재 페이지가 기기에 저장됩니다. 다만 이렇게 저장한 파일은 보통 .mhtml 형식입니다. MHTML은 크롬 안에서는 잘 열리지만, 다른 프로그램이나 업로드 화면에서는 인식하지 못하는 경우가 있습니다. "HTML 파일"을 요구하는 곳이라면 맞지 않을 수 있습니다.

아이폰 사파리

사파리에는 웹페이지를 .html 파일로 바로 저장하는 메뉴가 없습니다. 공유 버튼을 누른 뒤 상단의 "옵션"에서 PDF 형식을 고르고 파일 앱에 저장하는 방법이 가장 흔히 쓰입니다. iOS 버전에 따라 웹 아카이브 형식이 보이기도 하지만, 이 역시 HTML과는 다른 형식입니다.

방법 2. 인쇄 기능으로 PDF 만들기

대부분의 브라우저에서 공유 또는 메뉴의 "인쇄"를 누른 뒤 프린터 대신 "PDF로 저장"을 고르면 PDF 파일이 만들어집니다. 모양이 고정되어 보관과 제출에 편리하지만, 글자를 다시 편집하거나 코드를 확인할 수는 없습니다. 긴 표가 페이지 경계에서 잘리는 경우도 있으니 저장 후 한 번 넘겨 보는 것이 좋습니다.

방법 3. 담다로 .html 파일 만들기

담다는 휴대폰 브라우저만으로 진짜 .html 파일을 만들 수 있게 한 도구입니다. 상황에 따라 세 가지 입력 방식을 씁니다.

  • 주소로 가져오기: 뉴스, 블로그, 공지처럼 누구나 볼 수 있는 페이지
  • 저장 버튼: 로그인 후에만 보이는 조회 화면. 페이지를 연 상태에서 즐겨찾기에 등록한 버튼을 누르면, 보이는 그대로 저장됩니다.
  • 붙여넣기·파일: 이미 가지고 있는 HTML 코드를 정리해 다시 저장할 때

어떤 방식이든 저장 전에 미리보기로 모양을 확인하고, 필요하면 바로 인쇄하거나 PDF로 저장할 수도 있습니다.

어떤 방법을 골라야 할까

목적추천
나중에 다시 읽기만 하면 됨브라우저 기본 저장 또는 PDF
".html 파일"로 제출하거나 다른 프로그램에서 열어야 함담다
종이로 출력해야 함PDF 또는 담다 미리보기의 인쇄

저장 방식마다 결과물의 형식이 다르다는 점만 기억하면, 상황에 맞는 방법을 고르기가 훨씬 쉬워집니다. 형식별 차이는 HTML, MHTML, PDF 차이 글에서 더 자세히 다룹니다.
