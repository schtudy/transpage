사용법

최종 수정 2026년 9월 18일

담다는 웹페이지를 하나의 .html 파일로 저장하는 도구입니다. 컴퓨터의 "다른 이름으로 저장" 기능을 휴대폰에서도 쓸 수 있게 만든 것이라고 생각하면 됩니다. 상황에 따라 세 가지 방법 중 하나를 고르세요.

어떤 방법을 써야 하나요?

상황추천 방법
뉴스, 블로그, 공지사항처럼 누구나 볼 수 있는 페이지주소로 가져오기
학생부·성적 조회, 신청 내역처럼 로그인 후에만 보이는 페이지저장 버튼
이미 HTML 코드나 파일을 가지고 있을 때붙여넣기 · 파일

1. 주소로 가져오기

변환하기 화면의 입력칸에 주소를 붙여넣고 가져오기를 누릅니다. https://를 빼고 입력해도 자동으로 붙습니다. 가져온 페이지는 바로 아래 미리보기에 표시되며, 파일 이름을 바꾼 뒤 HTML 파일 저장을 누르면 됩니다.

이 방식은 담다의 서버가 대신 페이지를 열어 받아오는 구조입니다. 그래서 로그인 정보가 필요한 페이지, 해외 접속을 막아 둔 페이지, 자동 접속을 차단한 페이지는 가져올 수 없습니다. 이때는 저장 버튼을 이용하세요.

2. 저장 버튼 (로그인된 페이지용)

저장 버튼은 즐겨찾기에 넣어 두는 작은 코드입니다. 저장하고 싶은 페이지를 연 상태에서 누르면, 그 페이지 안에서 곧바로 화면 내용을 모아 .html 파일로 내려받습니다. 문서가 담다 서버를 거치지 않기 때문에 로그인이 필요한 개인 문서도 안전하게 저장할 수 있습니다.

저장 버튼이 하는 일

  • 입력칸에 적힌 값과 체크 상태를 파일에 함께 남깁니다. (비밀번호 칸은 제외)
  • 같은 사이트 안에서 불러온 프레임(iframe) 내용을 파일 안에 포함합니다.
  • 읽을 수 있는 스타일시트를 파일 안에 넣어, 인터넷 연결 없이도 모양이 최대한 유지되게 합니다.
  • 화면을 바꾸는 스크립트는 빼고 저장합니다.

추가 방법

안드로이드 크롬: 변환하기 화면에서 저장 버튼 코드 복사 → 아무 페이지나 즐겨찾기 추가 → 즐겨찾기 수정에서 이름은 "담다저장", 주소는 복사한 코드로 바꿉니다. 사용할 때는 주소창에 "담다저장"을 입력한 뒤 뜨는 즐겨찾기를 누릅니다.

아이폰 사파리: 코드를 복사한 뒤 아무 페이지나 북마크하고, 북마크 편집에서 주소를 복사한 코드로 바꿉니다. 사용할 때는 북마크 목록에서 누르면 됩니다.

일부 사이트는 보안 설정으로 즐겨찾기 코드 실행을 막아 두기도 합니다. 이 경우 브라우저 메뉴의 "페이지 저장"이나 "인쇄 → PDF로 저장"을 함께 활용해 보세요.

3. 붙여넣기 · 파일

HTML 코드를 붙여넣거나 .html 파일을 선택한 뒤 변환하기를 누릅니다. 원본 주소를 함께 적어 두면 상대 경로로 된 이미지와 스타일이 원본 주소 기준으로 바뀌어 깨지지 않습니다.

변환 옵션

  • 스크립트 제거: 광고, 팝업, 자동 이동 등 저장 파일에 필요 없는 동작을 없앱니다. 스크립트로 내용을 그리는 페이지라면 끄고 다시 시도하세요.
  • 링크·이미지 경로 유지: 상대 경로를 원본 주소 기준 절대 경로로 바꿉니다.
  • A4 인쇄 여백 적용: 인쇄할 때 A4 용지와 적당한 여백을 쓰고, 배경색이 빠지지 않게 합니다.

저장한 파일 열기와 인쇄

안드로이드는 보통 다운로드 폴더, 아이폰은 파일 앱의 다운로드 폴더에 저장됩니다. 파일을 누르면 브라우저에서 열립니다. 인쇄가 필요하면 미리보기의 인쇄 · PDF 버튼을 누르고, 프린터 대신 "PDF로 저장"을 고르면 PDF 파일로도 보관할 수 있습니다.

문제가 생겼을 때

  • "원본 사이트가 오류를 반환했습니다": 사이트가 자동 접속을 막았거나 로그인이 필요한 경우입니다. 저장 버튼을 쓰세요.
  • 글자가 깨져 보임: 파일은 UTF-8로 저장됩니다. 오래된 뷰어라면 브라우저로 열어 보세요.
  • 이미지가 안 보임: 원본 사이트가 외부 접근을 막은 이미지는 원본 사이트에 로그인한 상태에서만 보일 수 있습니다.
