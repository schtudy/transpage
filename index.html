⚠️ 저장 버튼은 공식 주소 transhtml.pages.dev에서만 받으세요. 다른 곳에서 받은 코드는 개인정보를 빼돌릴 수 있습니다.

저장 버튼 코드 확인하기 (외부 전송 없음)

이 코드는 화면 내용을 모아 기기에 파일로 저장만 합니다. fetch, XMLHttpRequest, sendBeacon 같은 외부 전송 명령이 없습니다. 비밀번호·숨은 보안값·스크립트는 저장하지 않습니다.

안드로이드 크롬에서 추가하기
  1. 위의 저장 버튼 코드 복사를 누릅니다.
  2. 이 페이지를 즐겨찾기(☆)에 추가한 뒤 수정을 누릅니다.
  3. 이름을 담다저장으로, 주소 칸을 지우고 복사한 코드를 붙여넣어 저장합니다.
  4. 저장할 페이지에서 주소창에 담다저장을 입력하고, 목록에 뜬 즐겨찾기를 누릅니다.
아이폰 사파리에서 추가하기
  1. 저장 버튼 코드 복사를 누릅니다.
  2. 공유 버튼 → 북마크 추가로 이 페이지를 북마크합니다.
  3. 북마크 목록에서 편집 → 방금 만든 북마크를 눌러 주소를 복사한 코드로 바꿉니다.
  4. 저장할 페이지에서 북마크 목록을 열고 해당 북마크를 누르면 파일 앱에 저장됩니다.
컴퓨터에서 추가하기
  1. 북마크바를 켭니다 (Ctrl/⌘ + Shift + B).
  2. 담다로 저장 버튼을 북마크바로 끌어다 놓습니다.

이렇게 동작합니다

  1. 가져오기

    주소를 넣거나, HTML을 붙여넣거나, 저장 버튼으로 지금 화면을 담습니다.

  2. 정리하기

    불필요한 스크립트를 빼고, 이미지와 스타일 경로를 원본 주소로 바꿔 깨지지 않게 합니다.

  3. 확인하고 저장

    미리보기로 모양을 확인한 뒤 .html 파일로 저장하거나 바로 인쇄합니다.

자주 묻는 질문

휴대폰에서 웹페이지를 HTML로 저장할 수 있나요?

네. 주소를 입력하거나, 로그인된 페이지라면 저장 버튼(즐겨찾기)을 눌러 .html 파일로 저장할 수 있습니다. 안드로이드는 다운로드 폴더, 아이폰은 파일 앱에 저장됩니다.

로그인해야 보이는 페이지도 저장되나요?

주소 입력 방식은 로그인 정보가 전달되지 않아 불가능합니다. 해당 페이지를 연 상태에서 저장 버튼을 누르면 화면에 보이는 그대로 저장됩니다. 이 과정에서 로그인 정보나 문서 내용은 담다로 전송되지 않습니다.

저장한 파일을 열었더니 모양이 조금 달라요.

일부 사이트는 스크립트로 화면을 그리거나 외부 파일 접근을 막아 둡니다. "스크립트 제거"를 끄고 다시 변환하거나, 저장 버튼 방식을 이용해 보세요.

변환한 내용이 서버에 남나요?

아니요. 변환과 미리보기는 브라우저 안에서만 이루어지며 결과물을 저장하지 않습니다. 자세한 내용은 개인정보처리방침을 참고하세요.

PDF로도 저장할 수 있나요?

미리보기의 "인쇄 · PDF"를 누른 뒤 프린터 대신 "PDF로 저장"을 선택하면 됩니다.

왜 담다인가요

휴대폰 브라우저의 기본 저장 기능은 대부분 MHTML이나 PDF로 저장합니다. 그래서 ".html 파일"이 필요한 순간에는 결국 컴퓨터를 찾게 됩니다. 담다는 이 과정을 휴대폰 하나로 끝낼 수 있게 만들었습니다.

개인 서류를 다루는 만큼 설계 원칙은 단순합니다. 문서는 사용자의 기기 밖으로 나가지 않고, 변환 화면에는 광고 같은 제3자 코드를 넣지 않으며, 저장 파일에는 비밀번호나 보안 토큰을 남기지 않습니다.
