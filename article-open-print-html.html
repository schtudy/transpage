저장한 HTML 파일 찾기·열기·인쇄·PDF 변환 방법

작성 2026.09.18 · 담다

HTML 파일을 저장했는데 어디에 있는지, 어떻게 열고 출력하는지 막막할 때가 있습니다. 기기별로 파일을 찾고, 열고, 인쇄하거나 PDF로 바꾸는 방법을 정리했습니다.

저장된 파일 찾기

안드로이드

기본 "내 파일" 또는 "파일" 앱을 열고 다운로드 폴더를 확인하세요. 크롬 메뉴의 "다운로드 항목"에서도 최근 받은 파일을 바로 열 수 있습니다.

아이폰

파일 앱의 "나의 iPhone" 또는 "iCloud Drive" 안의 다운로드 폴더에 저장됩니다. 사파리 주소창 오른쪽의 다운로드 아이콘을 눌러도 찾을 수 있습니다.

컴퓨터

브라우저의 다운로드 목록(Ctrl+J, 맥은 ⌘+Option+L)에서 확인할 수 있습니다.

파일 열기

HTML 파일을 누르면 대부분 브라우저에서 열립니다. 이때 코드가 아니라 웹페이지 모양으로 보이는 것이 정상입니다. 코드를 직접 확인하고 싶다면 담다의 붙여넣기·파일 탭에서 파일을 선택해 변환한 뒤 "HTML 코드 보기"를 누르세요.

안드로이드에서 파일을 눌러도 열리지 않는다면, 길게 눌러 "다른 앱으로 열기"에서 크롬이나 삼성 인터넷을 선택해 보세요.

인쇄하기

  1. 파일을 브라우저로 엽니다.
  2. 메뉴(또는 공유)에서 인쇄를 누릅니다.
  3. 프린터를 선택합니다. 무선 프린터가 같은 와이파이에 연결되어 있어야 합니다.
  4. 용지 크기(A4)와 여백을 확인한 뒤 인쇄합니다.

배경색이나 표 테두리가 빠진다면 인쇄 설정의 "배경 그래픽"을 켜세요. 담다 변환 시 "A4 인쇄 여백 적용" 옵션을 켜면 이 설정이 파일 안에 미리 들어갑니다.

PDF로 바꾸기

인쇄 화면에서 프린터 대신 PDF로 저장을 고르면 됩니다. 아이폰은 인쇄 미리보기 화면에서 공유 버튼을 눌러 파일 앱에 저장할 수 있습니다.

자주 생기는 문제

  • 이미지가 안 보임: 이미지가 원본 사이트 주소로 연결된 경우 인터넷 연결이 필요합니다. 원본 사이트에서 외부 접근을 막은 이미지는 보이지 않을 수 있습니다.
  • 표가 페이지에서 잘림: 인쇄 배율을 90% 정도로 줄이거나 가로 방향으로 바꿔 보세요.
  • 글자가 깨짐: 글자 깨짐 해결 방법을 참고하세요.
