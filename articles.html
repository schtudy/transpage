웹페이지 저장 가이드

웹페이지를 파일로 저장하고 활용하는 데 필요한 내용을 주제별로 정리했습니다.

  • 휴대폰에서 웹페이지를 HTML 파일로 저장하는 3가지 방법

    안드로이드 크롬과 아이폰 사파리에서 웹페이지를 파일로 저장하는 방법을 형식별 장단점과 함께 정리했습니다.

  • HTML, MHTML, PDF 차이 – 웹페이지 저장 형식 고르는 법

    웹페이지 저장 형식인 HTML, MHTML, PDF의 차이와 제출·보관·인쇄 목적별로 어떤 형식을 골라야 하는지 설명합니다.

  • 북마클릿이란? 즐겨찾기 코드를 안전하게 쓰는 5가지 원칙

    북마클릿의 원리와 위험성, 개인정보가 담긴 화면에서 안전하게 사용하는 원칙을 정리했습니다.

  • 저장한 HTML 파일 찾기·열기·인쇄·PDF 변환 방법

    안드로이드, 아이폰, 컴퓨터에서 저장한 HTML 파일을 찾고 열고 인쇄하거나 PDF로 바꾸는 방법을 안내합니다.

  • 저장한 웹페이지 한글 깨짐 원인과 해결 (UTF-8, EUC-KR)

    저장한 웹페이지의 한글이 깨지는 원인인 문자 인코딩과 UTF-8·EUC-KR 차이, 해결 방법을 설명합니다.

  • 개인 서류를 온라인 도구로 저장할 때 체크리스트

    성적표·증명서 같은 개인 서류를 온라인 도구로 변환·저장할 때 확인해야 할 보안 체크리스트입니다.

  • 담다가 필요한 순간 – 휴대폰으로 웹페이지를 파일로 남겨야 할 때

    컴퓨터 없이 .html 파일이 필요할 때, 로그인 화면을 보관할 때 등 담다가 도움이 되는 5가지 상황과 다른 방법과의 비교를 정리했습니다.

  • 담다의 보안 설계 – 문서가 서버로 가지 않는 이유

    담다가 개인 문서를 보호하는 5가지 설계 원칙과 저장 버튼이 파일에서 제외하는 정보, 사용자가 지켜야 할 점을 설명합니다.

  • 로그인이 필요한 페이지는 왜 주소로 저장이 안 될까

    로그인이 필요한 페이지나 스크립트로 그리는 페이지를 주소로 가져올 수 없는 이유와 저장 버튼·PDF를 이용한 해결 방법입니다.

  • 웹페이지 파일 제출 전 체크리스트 5단계

    저장한 웹페이지를 제출하기 전 형식·용량·내용·파일 이름을 점검하는 5단계 체크리스트와 인쇄 팁을 정리했습니다.
